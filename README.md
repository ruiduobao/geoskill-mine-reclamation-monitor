# geoskill-mine-reclamation-monitor

> Compare pre-mining and post-reclamation NDVI (or other vegetation indices) to assess how well a reclaimed mine site is recovering. Accepts two GeoTIFF rasters, or auto-downloads via `--bbox --date-range`.

See [SKILL.md](SKILL.md) for full usage, inputs and outputs.

## Quick start

```bash
python mine_reclamation_monitor.py --synthetic --output-dir ./test
```
